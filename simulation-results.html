Simulation Results

Planning accuracy in three simulated scenes: tabletop, kitchen, and workshop. Each cell is one natural-language instruction given to one language model and one planning method.

Plan asks the model for an action list directly. PDDL asks the model to write the planning problem. Our 1 selects a reusable domain and extends it with a missing robot skill when the task requires one. Our 2 does the same and also declares which objects can take part in the new skill. A result is correct when the method produces a suitable plan, or correctly refuses a task the robot cannot perform. Explicit instructions name the action; implicit instructions describe the desired outcome.
